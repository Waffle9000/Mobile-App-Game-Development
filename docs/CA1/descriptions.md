# Store descriptions – Whopper

## Short description (72 / 80 characters)
Swipe, jump and squish a runaway burger through a hazard-packed kitchen!

## Long description
Whopper is a fast, silly endless runner where you play as a burger on the run.

Escape the kitchen! Swipe to dodge flying hazards, jump over obstacles and squish
yourself flat to slide underneath them. The longer you survive, the faster it gets.

FEATURES
- Simple swipe controls: left and right to change lanes, up to jump, down to squish
- One kitchen world built from hand-made track sections
- Missions to complete as you run
- Speed and difficulty that ramp up the longer you last
- Pause anytime: the game pauses itself for calls and notifications
- Accessibility options: text size, haptics on/off, screen shake on/off

PLAY YOUR WAY
- Plays fully offline
- No ads
- No in-app purchases
- No account needed
