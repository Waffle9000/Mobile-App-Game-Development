# Title & one-line pitch
Whopper,

A mobile game where you squish and drag a burger in order to dodge the hazardous enviroment you are running away from.

# Aesthetics (target player feelings/experiences)

Fun, silly, tense and quick reflex-based fun with a comedic vibe.

# Core mechanics (3–5 verbs/systems)
 1. Drag (move the burger)
 2. Squish (shrink/dodge under obstacles)
 3. Dodge (avoid obstacles)
 4. Jump (Over obstacles)

# Dynamics (how play unfolds)
The burger continuously moves forward automatically. The player drags it left/right and squishes it to avoid obstacles that get faster and more frequent over time.

# Progression & content (levels/biomes/sessions; run length)
Endless runner style, one continuous run per session while the difficulty increases the longer you survive. There will be a kitchen level/biome which would transition into a farm level. There will be distance-based difficulty scaling.

# Performance budget (target frame-time, memory, load time)

# Monetisation (if any) & ethics notes
None planned for this assignment. No ads or in-app purchases.


# Risks & cuts list
 Risk: squish mechanic may be hard to get feeling right, could simplify to just drag/dodge if time runs short.
- First Cut: Make the game only one lane where the burger won't need to move left and right and will only need to  squish/jump
- Second cut: extra hazard types or biomes if time is tight.
